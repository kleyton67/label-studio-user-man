label_studio/users/api.py
  - imports: core.api_permissions.IsOrganizationAdmin, django.shortcuts.get_object_or_404,
    groups.models.UserGroup/UserGroupMember, rest_framework.serializers,
    rest_framework.exceptions.ValidationError.
  - AdminUserSerializer (ModelSerializer, model=User):
      fields = id, email, username, first_name, last_name, is_active, is_admin,
               date_joined, last_activity, groups
      read_only_fields = id, date_joined, last_activity, groups
      groups = SerializerMethodField -> [{"id": ..., "name": ...}] from
               user.user_group_memberships.select_related("group")
      (no password field, no password hash is ever serialized)
  - AdminUserCreateSerializer(AdminUserSerializer): adds write-only `password`
    (required), username optional (defaults to email local part); create() uses
    User.objects.create_user -> hashes password; post_save signal auto-creates Token.
  - AdminUserUpdateSerializer: writable email, first_name, last_name, is_active, is_admin.
  - AdminUserListAPI(ListCreateAPIView), permission_classes=[IsAuthenticated,
    IsOrganizationAdmin], queryset scoped to User.objects.filter(organizations=
    request.user.active_organization); POST creates + sets active_organization +
    organization.add_user(instance) (OrganizationMember). No active org -> 403.
  - AdminUserDetailAPI(RetrieveUpdateDestroyAPIView), same permissions/scoping,
    http_method_names=['get','patch','delete','head','options'] (no PUT).
      PATCH: rejects fields outside {email,first_name,last_name,is_active,is_admin}
        with 400; blocks changing is_admin of self or of the org owner (403);
        validates via AdminUserUpdateSerializer.
      DELETE: 403 on self; 403 on owner (created_by SET_NULL); else hard delete.
  - AdminUserGroupsAPI(APIView), same permissions/scoping:
      GET  -> {"groups": [{"id","name"}]}
      PUT  -> body {"groups": [ids]}; requires list of ints; rejects ids not in the
              active organization (400); replaces membership (delete + bulk_create
              with ignore_conflicts, deduped); returns the new list.
