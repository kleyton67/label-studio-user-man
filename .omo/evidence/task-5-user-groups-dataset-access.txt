# Task 5: Enforcement nas rotas de datasets (projects/tasks/annotations/DM/import/export)

## Summary
Implemented restrictive group-based access control on all dataset routes as specified in T5.

## Changes Made

### 1. projects/api.py
- **ProjectAPI.get_queryset()**: Changed from `Project.objects.with_counts().filter(organization=...)` to `Project.objects.with_counts().filter(pk__in=Project.objects.for_user(self.request.user).values('pk'))` to enforce group-based access
- **ProjectNextTaskAPI.get_queryset()**: Added `get_queryset()` method that returns `Project.objects.for_user(self.request.user)`
- **LabelStreamHistoryAPI.get_queryset()**: Added `get_queryset()` method that returns `Project.objects.for_user(self.request.user)`

### 2. tasks/api.py
- **TaskAPI.get_object()**: Added group-based access check after `check_object_permissions()`: `if not lean_task.project.has_permission(self.request.user): raise PermissionDenied(...)`
- **AnnotationAPI.get_queryset()**: Added `get_queryset()` method that uses `filter_accessible(Annotation.objects.all(), self.request.user, project_field='project')`

### 3. data_manager/api.py
- **TaskListAPI.get()**: Changed `generics.get_object_or_404(Project, pk=project_pk)` to `generics.get_object_or_404(Project.objects.for_user(request.user), pk=project_pk)`
- **ProjectColumnsAPI.get()**: Changed `generics.get_object_or_404(Project, pk=pk)` to `generics.get_object_or_404(Project.objects.for_user(request.user), pk=pk)`
- **ProjectStateAPI.get()**: Changed `generics.get_object_or_404(Project, pk=pk)` to `generics.get_object_or_404(Project.objects.for_user(request.user), pk=pk)`
- **ProjectActionsAPI.get()**: Changed `generics.get_object_or_404(Project, pk=pk)` to `generics.get_object_or_404(Project.objects.for_user(request.user), pk=pk)`
- **ProjectActionsAPI.post()**: Changed `generics.get_object_or_404(Project, pk=pk)` to `generics.get_object_or_404(Project.objects.for_user(request.user), pk=pk)`
- **ProjectActionsFormAPI.get()**: Changed `generics.get_object_or_404(Project, pk=pk)` to `generics.get_object_or_404(Project.objects.for_user(request.user), pk=pk)`

### 4. data_export/api.py
- **ExportFormatsListAPI.get_queryset()**: Changed from `Project.objects.filter(organization=self.request.user.active_organization)` to `Project.objects.for_user(self.request.user)`
- **ExportAPI.get_queryset()**: Changed from `Project.objects.filter(organization=self.request.user.active_organization)` to `Project.objects.for_user(self.request.user)`
- **ProjectExportFiles.get_queryset()**: Changed from `Project.objects.filter(organization=self.request.user.active_organization)` to `Project.objects.for_user(self.request.user)`

### 5. Test File Created

  - ProjectAPI access (5 tests)
  - ProjectTaskListAPI access (2 tests)
  - TaskAPI access (3 tests)
